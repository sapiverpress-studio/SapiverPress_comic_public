# Sapiver Press Comic Render Rules

- Character art first.
- Puzzle screen composited second.
- Minimal story text overlaid last.
- No generated puzzle grids.
- No giant title/header/footer.
- No large URL overlay.
- No blurry outline panel.
- Sapiver Press branding only on merchandise and monitor/browser URL.
- Text must continue the story, not repeat template copy.
- Use /daily/YYYY-MM-DD.json and /image-manifests/YYYY-MM-DD.json.
