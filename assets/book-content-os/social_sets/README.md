# Book Content OS social assets

Put the Book Content OS Lite + Pro social ZIPs here if storing assets directly in the runner workspace.

Preferred production path matches the existing FTPE workflow:

1. Upload the ZIPs to the shared Google Drive asset folder.
2. Add the resulting Drive file IDs to `config/book-content-os-social-drive-zips.json`.
3. Run **Book Content OS Social** manually from GitHub Actions.

Public post copy must use `link in bio` only. Do not print raw URLs in captions or first comments.
