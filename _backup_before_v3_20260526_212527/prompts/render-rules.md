# Sapiver Press Comic Render Rules

Use this for the manual/agent image stage until the compositor is fully automated.

## Locked rules

- Character art first.
- Puzzle screen composited second.
- Minimal story text overlaid last.
- No generated puzzle grids.
- No giant title/header/footer.
- No large URL overlay.
- No blurry outline panel.
- Sapiver Press branding only on merchandise and monitor/browser URL.
- Text must continue the story, not repeat template copy.
- Use the daily JSON from `/daily/YYYY-MM-DD.json`.
- Use the image manifest from `/image-manifests/YYYY-MM-DD.json`.

## Current good direction

Clean comic scene.
Real puzzle on screen.
Small speech bubble.
One bottom caption.
Merch branding only.
Monitor/browser URL only.
